# 言の葉Slash

##  概要
- このプロジェクトは、Unityを用いて制作したブラウザゲームです。
- 難易度を選択し、上から降ってくる言葉を切ってハイスコアを目指しましょう。
- 悪い言葉を切るとポイントを獲得し、良い言葉を切るとポイントが減少します。

##  技術詳細
- **Unity**: ゲームロジック、オブジェクトの配置、ゲーム上のUI
- **C#**: 落下速度や得点の計算やBGMを流すなどのスクリプト作成
- **Git**: ブランチ運用、GithubとGithubDesktopを利用
